# Objective

Copy all 10 `halcytone_contracts` source files and 2 data artifacts into `halcytone/contracts/` in the new monorepo, rewrite every internal import from `halcytone_contracts.*` to `halcytone.contracts.*`, and wire the top-level `halcytone/__init__.py` to re-export the same 24-name public surface. This is the foundation that unblocks T3.3, T3.4, T3.5.

# Implementation Plan

Working directory for all steps: `/home/kmasty/projects/halcytone/`.

1. Copy source files from `/home/kmasty/projects/halcytone-contracts/halcytone_contracts/` → `halcytone/contracts/`:
   - `signals.py`, `state.py`, `session.py`, `storage.py`, `drift.py`, `baseline.py`, `summary.py`, `__init__.py`
   - `bundles/__init__.py`, `bundles/manifest.py`
2. Copy data artifacts:
   - `storage.sql` → `halcytone/contracts/storage.sql`
   - `bundles/manifest.schema.json` → `halcytone/contracts/bundles/manifest.schema.json`
3. Grep + rewrite all internal imports: `from halcytone_contracts.X import Y` → `from halcytone.contracts.X import Y`. Source-wide grep after rewrite must show 0 matches for `halcytone_contracts`.
4. Update `halcytone/contracts/__init__.py` to bump `__contract_version__ = "0.3.0"` (up from 0.2.0).
5. Rewrite `halcytone/__init__.py` to re-export the full 24-name surface from `halcytone.contracts` — explicit imports + `__all__` list, not `from halcytone.contracts import *`.
6. Update `pyproject.toml` `[tool.setuptools.package-data]`:
   - `halcytone.contracts = ["*.sql"]`
   - `"halcytone.contracts.bundles" = ["*.json"]`
7. Verify `read_ddl()` in `halcytone/contracts/storage.py` uses `importlib.resources.files("halcytone.contracts")` after the rename.
8. Smoke-import: `python -c "from halcytone import SignalPacket, Baseline, SessionManifest; print('OK')"`.
